# 🖼️ Word of the Day 이미지 추가 가이드

## 📍 어디에 이미지를 넣나요?

### ✅ 방법 1: 로컬 리포지토리에 넣기 (추천)

```
word-of-the-day/
├── eloquent/
│   ├── index.html
│   └── eloquent.jpg       ← 여기에 넣으세요!
├── resilience/
│   ├── index.html
│   └── resilience.png
└── precaution/
    └── index.html
```

**장점:**
- ✅ 버전 관리 가능
- ✅ 파일과 이미지가 함께 관리됨
- ✅ 빠른 로딩 속도
- ✅ 이미지가 사라질 걱정 없음

**단점:**
- ❌ 리포지토리 크기 증가
- ❌ 매번 git push 필요

### ⚡ 방법 2: 이미지 URL 사용하기

외부 이미지 호스팅 서비스 사용:
- Imgur (https://imgur.com)
- Cloudinary (https://cloudinary.com)
- AWS S3
- Google Drive (공개 링크)

**장점:**
- ✅ 리포지토리 크기 작게 유지
- ✅ Git 작업 불필요
- ✅ 대용량 이미지도 OK

**단점:**
- ❌ 외부 서비스 의존
- ❌ 링크 깨질 수 있음
- ❌ 로딩 속도 변동 가능

## 🚀 사용 방법

### 방법 1을 사용할 때 (로컬 파일)

#### 1단계: 이미지 준비
```bash
# 이미지를 원하는 위치에 준비
# 예: /Users/yourname/Downloads/eloquent.jpg
```

#### 2단계: 스크립트 실행
```bash
cd /workspace/backend
node scripts/create-word-with-image.js
```

#### 3단계: 이미지 경로 입력
```
📷 이미지 파일 (선택사항):
   방법 1: 이미지 파일 경로 입력
   방법 2: 이미지 URL 입력
   방법 3: 나중에 수동으로 추가 (빈 칸)
이미지: /Users/yourname/Downloads/eloquent.jpg
```

스크립트가 자동으로:
- ✅ 이미지를 단어 폴더로 복사
- ✅ HTML에 이미지 태그 추가
- ✅ OG 이미지 메타 태그 추가

#### 4단계: GitHub에 푸시
```bash
cd /workspace
git add word-of-the-day/eloquent/
git commit -m "Add Word of the Day: eloquent with image"
git push
```

### 방법 2를 사용할 때 (URL)

#### 1단계: 이미지를 호스팅 서비스에 업로드
예: Imgur에 업로드하고 링크 복사
```
https://i.imgur.com/abc123.jpg
```

#### 2단계: 스크립트 실행 시 URL 입력
```
이미지: https://i.imgur.com/abc123.jpg
```

스크립트가 자동으로:
- ✅ HTML에 URL로 이미지 태그 추가
- ✅ OG 이미지 메타 태그에 URL 포함

#### 3단계: API에만 전송
```bash
node scripts/post-word-to-api.js eloquent
```

## 📸 이미지 준비 팁

### 권장 사양
- **형식**: JPG, PNG, WebP
- **크기**: 1200×630px (소셜 미디어 최적화)
- **최대 파일 크기**: 500KB 이하
- **비율**: 16:9 또는 1:1

### 이미지 압축
큰 이미지는 압축하세요:
- TinyPNG (https://tinypng.com)
- Squoosh (https://squoosh.app)
- ImageOptim (Mac)

### 좋은 이미지 찾기
무료 이미지 사이트:
- Unsplash (https://unsplash.com)
- Pexels (https://pexels.com)
- Pixabay (https://pixabay.com)

**검색 팁**: 단어의 개념을 시각적으로 표현하는 이미지 선택
- `eloquent` → 연설하는 사람, 마이크
- `resilience` → 강한 나무, 회복
- `precaution` → 안전 장비, 경고 표시

## 🔧 수동으로 이미지 추가하기

이미 생성한 단어에 나중에 이미지를 추가하려면:

### 1. 이미지 파일 복사
```bash
cp /path/to/your-image.jpg /workspace/word-of-the-day/eloquent/eloquent.jpg
```

### 2. index.html 수정
`word-of-the-day/eloquent/index.html` 파일을 열어서 다음 부분을 찾아 이미지 섹션 추가:

```html
<article class="wotd-card">
  <header class="wotd-header">
    ...
  </header>

  <!-- 여기에 추가 -->
  <section class="wotd-image-section">
    <img src="eloquent.jpg" 
         alt="eloquent illustration" 
         class="wotd-main-image"
         loading="lazy">
  </section>

  <section class="wotd-meaning">
    ...
  </section>
</article>
```

### 3. CSS 추가 (head 섹션에)
```html
<style>
.wotd-image-section {
  margin: 1.5rem 0;
  text-align: center;
}
.wotd-main-image {
  max-width: 100%;
  height: auto;
  border-radius: 12px;
  box-shadow: 0 4px 6px rgba(0, 0, 0, 0.1);
  max-height: 400px;
  object-fit: cover;
}
</style>
```

### 4. OG 이미지 메타 태그 추가 (head 섹션에)
```html
<meta property="og:image" content="https://englisheasystudy.com/word-of-the-day/eloquent/eloquent.jpg">
<meta name="twitter:image" content="https://englisheasystudy.com/word-of-the-day/eloquent/eloquent.jpg">
<meta name="twitter:card" content="summary_large_image">
```

### 5. Git 커밋
```bash
git add word-of-the-day/eloquent/
git commit -m "Add image to eloquent"
git push
```

## ❓ FAQ

### Q1: GitHub에 이미지가 너무 많으면 문제가 되나요?
**A**: 일반적으로 괜찮지만, 100개 이상의 고해상도 이미지가 있다면 LFS(Large File Storage)를 고려하세요.

### Q2: 이미지 없이 만들고 나중에 추가할 수 있나요?
**A**: 네! 위의 "수동으로 이미지 추가하기" 섹션을 참고하세요.

### Q3: WebP 형식도 지원하나요?
**A**: 네! JPG, PNG, WebP 모두 지원합니다. WebP를 사용하면 파일 크기를 30-50% 줄일 수 있습니다.

### Q4: 이미지가 너무 크면 어떻게 하나요?
**A**: TinyPNG나 Squoosh로 압축하세요. 보통 500KB 이하로 유지하는 것이 좋습니다.

### Q5: Imgur 말고 다른 무료 호스팅은?
**A**: 
- Cloudinary (무료 25GB)
- ImgBB (무료, 무제한)
- Postimages (무료, 무제한)

### Q6: 이미지가 안 보여요!
**체크리스트:**
- [ ] 파일 경로가 올바른가?
- [ ] 파일 이름 대소문자가 맞나?
- [ ] 이미지 파일이 실제로 업로드되었나?
- [ ] URL이 공개(public)로 설정되었나?
