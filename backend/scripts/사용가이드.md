# Word of the Day 생성 도구 - 한글 가이드

## 📖 개요

이 도구를 사용하면 `precaution`과 같은 형식의 "오늘의 단어" 콘텐츠를 쉽게 생성할 수 있습니다.

## 🎯 주요 기능

1. ✅ 정적 HTML 파일 자동 생성 (SEO 최적화)
2. ✅ API용 JSON 데이터 생성
3. ✅ 대화형 입력 지원
4. ✅ API 자동 전송

## 🚀 빠른 시작

### 방법 1: 미리 작성한 데이터로 생성하기

```bash
# 1. 터미널 열기
cd /workspace/backend

# 2. create-word-of-day.js 파일 열어서 WORD_DATA 수정
nano scripts/create-word-of-day.js

# 3. 스크립트 실행
node scripts/create-word-of-day.js

# 4. (선택) API에 바로 전송
node scripts/post-word-to-api.js eloquent
```

### 방법 2: 대화형으로 생성하기 (추천!)

```bash
# 1. 터미널 열기
cd /workspace/backend

# 2. 대화형 스크립트 실행
node scripts/create-word-interactive.js

# 3. 질문에 답하기
단어 (영어): eloquent
발음 기호: /ˈel.ə.kwənt/
품사: adjective
...

# 4. (선택) API에 바로 전송
node scripts/post-word-to-api.js eloquent
```

## 📝 입력해야 할 정보

### 필수 정보
- **단어**: 영어 단어 (예: eloquent)
- **발음**: IPA 발음 기호 (예: /ˈel.ə.kwənt/)
- **품사**: noun, verb, adjective 등
- **한글 뜻**: 간단한 한글 뜻
- **영어 정의**: 영어로 된 정의

### 예문 (3개 이상)
각 예문마다:
- 영어 문장
- 한글 번역

### 주요 표현 (3개 이상)
각 표현마다:
- 표현 (예: eloquent speech)
- 뜻 (예: 웅변적인 연설)

### 추가 정보
- **유의어**: 쉼표로 구분된 유의어 목록
- **Slug**: URL에 사용될 고유 식별자 (보통 단어와 동일)
- **비밀번호**: 나중에 수정/삭제할 때 사용

## 💡 팁과 요령

### 1. 발음 기호 찾기
- Cambridge Dictionary: https://dictionary.cambridge.org/
- Merriam-Webster: https://www.merriam-webster.com/

### 2. 좋은 예문 만들기
- 실생활에서 자주 쓰이는 상황
- 다양한 문맥 (긍정/부정/중립)
- 적절한 길이 (너무 길거나 짧지 않게)

### 3. 주요 표현 선정
- 가장 자주 쓰이는 콜로케이션
- 시험에 자주 나오는 표현
- 실용적인 표현

### 4. Slug 작성 규칙
- 소문자만 사용
- 공백 대신 하이픈(-) 사용
- 특수문자 제외
- 예: "take precautions" → "take-precautions"

## 🔧 문제 해결

### Q: 이미 존재하는 단어라고 나옵니다
```bash
# 기존 폴더 삭제 후 재시도
rm -rf /workspace/word-of-the-day/eloquent
```

### Q: API 전송이 실패합니다
```bash
# 1. API 데이터 확인
cat /workspace/backend/scripts/eloquent-api-data.json

# 2. curl로 직접 테스트
curl -X POST \
  https://port-0-englishwitheasyword-backend-1272llwoib16o.sel5.cloudtype.app/wordofday \
  -H "Content-Type: application/json" \
  -d @scripts/eloquent-api-data.json
```

### Q: 비밀번호를 잊어버렸습니다
- 백엔드 관리자 권한으로 삭제해야 합니다
- 또는 데이터베이스에서 직접 수정
