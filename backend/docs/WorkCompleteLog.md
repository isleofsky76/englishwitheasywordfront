## 사용 방법

1. 작업이 끝나면 **맨 아래 번호 +1** 로 행을 추가한다.  
2. `Homepageredesignplan.md` 체크박스를 `[x]`로 바꾼 뒤, **같은 날** 이 로그에도 남긴다.  
3. 부분만 끝냈으면 상태 `부분완료`, remark에 남은 일을 적는다.  
4. 배포가 필요하면 remark에 커밋/캐시 버전을 적는다.
