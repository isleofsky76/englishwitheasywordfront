불어넣다, 스며들게 하다와 심어주다

2026.09.04 00:00 · 조회 0 · 추천수 0

감정이나 생각, 지식, 태도 등을 사람이나 대상에 불어넣거나 스며들게 할 때 쓰이는 단어들을 모아 봤습니다.

1. 불어넣다·스며들게 하다

imbue(ɪmˈbjuː / 임뷰)

2. 스며들게 하다·가득 채우다

infuse(ɪnˈfjuːz / 인퓨즈)

3. 몰입시키다·푹 빠지게 하다

immerse(ɪˈmɜːrs / 이머스)

4. 심어주다·주입하다

instill(ɪnˈstɪl / 인스틸)

5. 전하다·나누어 주다

impart(ɪmˈpɑːrt / 임파트)

6. 주입시키다·세뇌하다

indoctrinate(ɪnˈdɑːktrəneɪt / 인닥트러네이트)
