1. 해 달라고 부탁하다

ask(ɑːsk / 애스크)

2. 공식적으로 요청하다

request(rɪˈkwest / 리퀘스트)

3. 도움·허락 등을 구하다

seek(siːk / 시크)

4. 간청[요청]하다

solicit(səˈlɪsɪt / 솔리싯)

5. 진정[탄원/청원]하다

petition(pəˈtɪʃn / 퍼티션)

6. 간청하다

plead(pliːd / 플리드)

7. 간청[애원]하다

entreat(ɪnˈtriːt / 인트리트)

8. 애원하다

beg(beɡ / 베그)

9. 애원[간청]하다

implore(ɪmˈplɔː / 임플로어)

10. 간청하다, 애원하다

beseech(bɪˈsiːtʃ / 비시치)

11. 간절히 원하다, 애원[탄원]하다

supplicate(ˈsʌplɪkeɪt / 서플리케이트)

12. 성가시게 조르다

pester(ˈpestə / 페스터)

13. 계속 들볶다

badger(ˈbædʒə / 배저)

14. 집요하게 졸라대다

importune(ˌɪmpəˈtjuːn / 임포튠)

15. 공개적으로 요구하다

call for(kɔːl fɔː / 콜 포)

16. (큰 소리로) 요구하다

clamor(ˈklæmə / 클래머)

17. 고집하며 요구하다

insist(ɪnˈsɪst / 인시스트)

18. 강하게 요구하다

demand(dɪˈmɑːnd / 디맨드)
