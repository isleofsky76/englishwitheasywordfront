다양한 밑줄·마킹 방법

cf 필드에 <mark1>~<mark12> 태그를 넣어 학습 단어를 시각적으로 강조합니다.

🎯 마킹 타입 미리보기

동일한 예문에서 privileged만 마킹 타입을 바꿔 비교합니다.

📄 HTML 사용법

<p>"That's <mark1>privileged</mark1> information," Jobs shot back.</p>

⚛️ React에서 사용하기

function VocabCard({ vocabData }) {
  return (
    <p>
      {vocabData.cf.split('<').map((part, i) => {
        if (part.includes('mark')) {
          const tag = part.match(/mark\d+/)[0];
          const text = part.match(/>(.*?)<\/mark/)[1];
          return React.createElement(tag, { key: i }, text);
        }
        return part;
      })}
    </p>
  );
}

📄 JavaScript (동적 마킹)

function addMarking(text, word, markType) {
  const regex = new RegExp(`\\b(${word})\\b`, 'gi');
  return text.replace(regex, `<${markType}>$1</${markType}>`);
}

const result = addMarking(
  "That's privileged information,\" Jobs shot back.",
  'privileged',
  'mark2'  // 'mark1', 'mark3' … 등
);
